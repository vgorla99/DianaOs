# Skill: Plan Then Edit
## Description
Forces a plan before touching code — prevents scope creep and regressions.
## Instructions
1. Identify exact entry points (routes/services/agents) to modify
2. List 3–6 implementation steps
3. Call out 1–3 risks or edge cases
4. Only then begin editing files
5. Do not refactor unrelated code
6. After editing, summarize what changed and what didn't
